# Interior, architecture, or spatial concept

- State site or room type, intended users, viewpoint, camera height, dimensions
  or proportions, circulation, fixed elements, materials, lighting, season,
  time, and level of realism.
- When editing a real space, preserve structural geometry, doors, windows,
  columns, camera position, and any object the user marks fixed. Change only the
  requested surfaces, furniture, landscape, weather, or lighting.
- Separate mood from feasibility. Do not imply that an image validates
  structure, code compliance, accessibility, cost, or constructability.
- Check scale, perspective, egress, furniture support, repeated objects,
  reflections, daylight direction, and indoor/outdoor continuity.
- Forbid impossible openings, floating fixtures, blocked paths, accidental room
  expansion, invented views, and watermarks.
