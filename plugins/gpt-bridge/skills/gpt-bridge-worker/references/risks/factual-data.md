# Factual and data overlay

- Treat supplied or independently verified facts as the only source of truth.
  Give exact values, units, labels, categories, dates, and relationships.
- Explicitly forbid invented facts, interpolated values, fake citations,
  unsupported anatomy, and unlabeled decorative data.
- Check totals, ordering, scale, units, signs, node relationships, labels, and
  whether the visual claim matches the data—not only whether it looks polished.
- Use the image model for visual composition, not arithmetic or fact
  discovery. For dense charts, precise maps, measurements, or regulated
  content, render data and labels deterministically and use generated imagery
  only as a supporting layer.
- If uncertainty is intentional, encode it explicitly with ranges, confidence,
  or “illustrative/not to scale” language.
