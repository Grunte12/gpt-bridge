# Infographic

- Treat the prompt as an artifact specification, not a decorative scene.
- State the audience, headline, reading order, exact facts/data, sections,
  comparisons, legends, and callouts.
- Use strong hierarchy, generous spacing, concise quoted text, consistent icons,
  and high contrast.
- Forbid decorative clutter, fake data, stock-photo styling, tiny copy,
  unrelated logos, watermarks, and invented claims.
