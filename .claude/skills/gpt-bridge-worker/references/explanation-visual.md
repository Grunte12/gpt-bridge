# Explanation or educational visual

- State the audience, learning goal, prerequisite knowledge, and the one concept
  the viewer should understand afterward.
- Use a numbered sequence, before/after comparison, cutaway, annotated process,
  or cause-and-effect flow that matches the concept.
- Keep labels short and concrete. Use callouts only where they improve
  comprehension.
- Forbid unexplained symbols, invented facts, decorative trivia, and watermarks.
