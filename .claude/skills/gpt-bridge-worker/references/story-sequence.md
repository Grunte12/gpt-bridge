# Comic, storyboard, or recurring-character sequence

- Define the audience, format, reading direction, panel/shot count, emotional
  arc, and what changes from beat to beat.
- Create a compact visual bible before generation: character silhouette, face,
  age, proportions, wardrobe, palette, signature objects, environment, medium,
  camera language, and forbidden drift.
- Use an accepted character or style frame as a reference for later images.
  Repeat invariants in every prompt; describe only the new action, expression,
  framing, and environment delta.
- For comics, state panel boundaries, balloon ownership, exact copy, reading
  order, and whether captions are allowed. Keep text brief.
- Check identity, handedness, wardrobe, props, time of day, screen direction,
  panel order, and continuity. Regenerate only the broken frame when possible.
