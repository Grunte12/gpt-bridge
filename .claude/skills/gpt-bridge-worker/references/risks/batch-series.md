# Batch and series overlay

- Define a compact series bible once: audience, purpose, aspect ratio, palette,
  typography character, lighting, camera language, margins, recurring motif,
  invariants, and file naming.
- Generate and accept one anchor asset before expanding the set. Use it as a
  reference for later outputs instead of describing the style from memory.
- Give each asset one controlled variable and repeat the shared invariants.
  Record a short manifest mapping filename to purpose, exact copy, sources, and
  accepted version outside the main-agent context.
- For multi-size campaigns, create one composition with explicit safe zones,
  then derive crops locally when possible. Independently regenerating every
  size increases drift.
- Review the set as a contact sheet or rendered deck for cross-asset color,
  identity, scale, typography, margins, chronology, and accidental duplicates.
  Fix only affected assets.
