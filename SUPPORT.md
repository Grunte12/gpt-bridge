# Support and contribution policy

GPT Bridge is an independent, local-first open-source project under the MIT
license. It is not an official OpenAI product and is not offered as a hosted or
managed service.

Useful issues and pull requests include reproducible local setup bugs, security
or privacy improvements, clear documentation fixes, and small compatibility
fixes with tests. Never include cookies, bearer tokens, copied requests,
browser profiles, `.env`, or private artifact links in an issue or pull request.

Do not request public-hosting, account-sharing, resale, challenge-bypass, or
provider-control-evasion features. Those are outside the project boundary.

Before submitting a change, run the checks in `docs/RELEASE_CHECKLIST.md` and
read `SECURITY.md` and `DISCLAIMER.md`.

## ภาษาไทย

GPT Bridge เป็นโครงการ open source แบบ local-first ไม่ใช่บริการทางการหรือ hosted
service ของ OpenAI รับ issue/PR ที่ reproduce ได้เกี่ยวกับ setup, bug, privacy,
security หรือเอกสารเท่านั้น ห้ามใส่ cookie, token, capture, `.env` หรือ link ไฟล์
ส่วนตัวใน issue/PR และไม่รับ feature สำหรับ public proxy, share account, ขาย access
หรือ bypass ข้อจำกัดของผู้ให้บริการ
